## 🧠 What You Will Learn

### Package Management

Package managers provide a controlled way to install, update, search, and remove software.

Debian-based systems commonly use:

```bash
apt
```

RPM-based systems commonly use:

```bash
yum
dnf
```

---

- Remove software.
- Check installed software.

## 🛡️ Security Perspective

Package management is an important part of system security.

Keeping software updated helps reduce exposure to known vulnerabilities.

Administrators should:

- Install software from trusted repositories.
- Keep packages updated.
- Remove unnecessary software.
- Monitor available storage.
- Avoid installing unknown packages.

---

## ⚠️ Best Practices

- Verify package names before installation.
- Use official repositories whenever possible.
- Avoid unnecessary administrative privileges.
- Review packages before removing them.
- Monitor disk usage regularly.
- Keep production systems properly maintained.
