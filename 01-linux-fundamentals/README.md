# 01 — Linux Fundamentals

This section introduces the fundamental concepts required to work effectively with Linux systems.

The goal is to become comfortable navigating the filesystem, managing files and directories, working with links, understanding permissions, and using Linux text editors.

## Skills Covered

- Linux filesystem structure
- Absolute and relative paths
- Directory navigation
- Creating and managing files
- Copying and moving files
- Removing files and directories
- File viewing commands
- Wildcards and pattern matching
- Hard links
- Symbolic links
- Linux file permissions
- Basic text editors

---

## Why This Matters for Cybersecurity

Linux fundamentals are the foundation of Linux administration and cybersecurity.

Security tools, servers, cloud infrastructure, containers, SIEM platforms, and many security appliances rely heavily on Linux.

Before moving into advanced security concepts, it is important to understand how Linux stores, manages, and protects information.
