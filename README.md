# Linux Administration & Security Guide

> A practical, hands-on journey through Linux administration, networking, automation, and security.

## 📖 About This Guide

This repository is a structured collection of practical Linux labs, notes, commands, and exercises designed to build strong real-world Linux administration and cybersecurity skills.

The guide starts with Linux fundamentals and progressively moves toward system administration, networking, automation, monitoring, and security.

The goal is not just to memorize commands, but to understand **how Linux works and how it is administered and secured in real environments.**

---

## 🎯 Learning Objectives

By completing this guide, you will develop practical experience with:

- Linux filesystem and directory structure
- Command-line administration
- Bash and shell scripting
- Users, groups, ownership, and permissions
- Processes and services
- Package management
- Networking and troubleshooting
- SSH and secure file transfer
- Disk management and filesystems
- LVM and swap
- Task scheduling with Cron
- System logs and monitoring
- Firewalls and network security
- SELinux
- Linux security practices
- System administration

## 🛠️ Environment

The labs are primarily designed around Linux environments such as:

- Ubuntu
- Debian
- RHEL-based distributions

Some exercises may require:

- A virtual machine
- Root/sudo privileges
- Multiple Linux systems
- Network connectivity

Always understand a command before executing it, especially commands involving disks, permissions, networking, or system configuration.
