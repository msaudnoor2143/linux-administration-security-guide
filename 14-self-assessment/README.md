# 🧠 Linux Administration & Security Guide — Self-Assessment

Welcome to **Section 14: Self-Assessment**.

This section provides a structured evaluation system covering the complete **60-lab Linux Administration & Security Guide**.

The purpose of this section is not simply to test whether you remember commands. It is designed to evaluate whether you can **understand Linux concepts, execute administrative tasks, troubleshoot problems, and apply security principles in practical situations**.

---

By completing these assessments, you should be able to evaluate your ability to:

- Navigate and manage Linux systems
- Work confidently with files and directories
- Understand permissions and ownership
- Use shells and environment variables
- Write and execute basic shell scripts
- Manage processes and jobs
- Work with archives and compression
- Manage software packages
- Inspect system hardware and disk usage
- Manage users and groups
- Apply password policies
- Schedule automated tasks
- Access systems remotely using SSH
- Transfer files securely
- Process and search text
- Inspect system logs
- Manage systemd services
- Configure Linux firewalls
- Manage partitions and mounted filesystems
- Configure swap and LVM
- Manage `/etc/fstab`
- Customize the shell environment
- Use regular expressions
- Transfer files over the network
- Perform system maintenance
- Monitor system resources
- Understand SELinux security controls

# 🧪 Assessment Philosophy

These assessments should evaluate more than memorization.

A strong candidate should be able to:

### 1. Understand

Explain what a command or configuration does.

### 2. Execute

Use the appropriate Linux commands correctly.

### 3. Analyze

Interpret command output and system information.

### 4. Troubleshoot

Identify problems and determine reasonable corrective actions.

### 5. Secure

Consider permissions, access control, firewall configuration and system security.

### 6. Document

Clearly explain what was performed and why.

---

# ⚠️ Assessment Safety

Perform practical assessments only inside an appropriate Linux environment such as:

- A personal Linux installation
- A virtual machine
- A dedicated training environment
- An authorized laboratory system

Do not modify systems that you do not own or have explicit permission to administer.

Storage, firewall, networking and security exercises should be performed carefully because incorrect configuration can affect system availability.

---

# 📝 Recommended Assessment Rules

Before beginning an assessment:

- Read the entire task before executing commands.
- Work in an authorized environment.
- Create backups where appropriate.
- Avoid blindly copying commands.
- Understand the purpose of each command.
- Record important results.
- Verify configuration changes.
- Clean up temporary resources when appropriate.
- Document troubleshooting steps.
