# Section 04 — User & Access Management

This section focuses on Linux user accounts, groups, and password policies.

User and access management is a fundamental responsibility of Linux system administrators and is closely connected to system security.

---

By completing this section, you will:

- Create and manage Linux users.
- Delete user accounts safely.
- Understand Linux groups.
- Manage group membership.
- Understand password policies.
- Apply basic principles of account security.

## 🧠 What You Will Learn

### User Accounts

Linux uses individual user accounts to control access to system resources.

You will learn how to:

- Create users.
- Set passwords.
- Inspect user information.
- Remove users.

---

### Groups

Groups allow administrators to organize users and manage permissions efficiently.

You will learn about:

- Primary groups.
- Supplementary groups.
- Group membership.
- Group management.

---

### Password Policies

Password policies help establish requirements for account security.

You will learn about concepts such as:

- Password configuration.
- Password expiration.
- Account security.
- Administrative controls.

---

## 🛡️ Security Perspective

Poor account management can create significant security risks.

Good practices include:

- Use individual accounts.
- Avoid unnecessary privileged access.
- Remove unused accounts.
- Apply appropriate password policies.
- Review group membership regularly.
- Give users only the access they need.

---

## ⚠️ Best Practices

- Do not share personal accounts.
- Avoid giving unnecessary administrative privileges.
- Verify users before deleting accounts.
- Review privileged groups carefully.
- Use strong authentication practices.
- Remove inactive accounts when appropriate.
