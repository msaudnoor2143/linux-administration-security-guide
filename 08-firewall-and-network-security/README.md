## 🧠 What You Will Learn

### Firewalls

A firewall controls network traffic according to defined rules.

You will learn concepts such as:

- Allowing traffic.
- Blocking traffic.
- Network ports.
- Protocols.
- Firewall rules.

---

### UFW

UFW provides a simpler interface for managing firewall rules on many Debian-based systems.

---

### iptables

iptables provides a more detailed interface for controlling packet filtering and network traffic.

You will learn its fundamental concepts and commands.

---

## 🛡️ Security Perspective

Firewalls are an important layer of host security.

Proper firewall configuration can help:

- Restrict unnecessary network access.
- Reduce attack surface.
- Control exposed services.
- Enforce network-access policies.

---

## ⚠️ Best Practices

- Understand a firewall rule before applying it.
- Avoid accidentally blocking required administrative access.
- Keep rules minimal and purposeful.
- Review firewall configurations regularly.
- Test changes carefully.
- Document important rules.
