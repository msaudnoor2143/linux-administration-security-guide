## 🧠 What You Will Learn

### System Logs

Linux systems generate logs that record important events and activities.

You will learn how to inspect logs for troubleshooting and system analysis.

---

### systemd

systemd is responsible for managing many system services and components on modern Linux distributions.

You will learn the basic concepts of:

- Services.
- Service status.
- Starting services.
- Stopping services.
- Enabling services.
- Disabling services.

---

## 🛡️ Security Perspective

Logs are an important source of security information.

Administrators can use them to investigate:

- Authentication activity.
- Service problems.
- System events.
- Unexpected behavior.

Service management is also important because unnecessary services can increase the system's attack surface.

---

## ⚠️ Best Practices

- Monitor important logs regularly.
- Do not delete logs without understanding their purpose.
- Avoid enabling unnecessary services.
- Verify service status after making changes.
- Protect access to sensitive logs.
