# Section 12 — Logging & System Maintenance

This section focuses on practical Linux maintenance, cron-log inspection, log rotation, shell aliases, and system monitoring.

These skills help administrators maintain systems and identify potential operational issues.

## 🧠 What You Will Learn

### Cron Logs

You will learn how to inspect logs related to scheduled tasks.

This can help identify whether scheduled operations are working correctly.

---

### Log Rotation

Log rotation helps manage growing log files.

You will learn the basic concept of:

- Rotating logs.
- Managing log size.
- Maintaining historical logs.

---

### Bash Aliases

Aliases allow frequently used commands to be represented by shorter names.

You will learn how aliases can improve command-line productivity.

---

### System Monitoring

You will use:

```bash
top
htop
```

to observe system activity.

You will learn to examine information related to:

- Processes.
- CPU usage.
- Memory usage.
- System activity.

---

## 🛡️ Security Perspective

Logs can provide valuable information during security investigations.

System monitoring can also help identify unusual resource consumption or unexpected processes.

Administrators should:

- Protect log files.
- Monitor important systems.
- Investigate unusual activity.
- Avoid deleting useful logs unnecessarily.

---

## ⚠️ Best Practices

- Monitor important systems regularly.
- Keep useful logs available.
- Configure log rotation appropriately.
- Be careful when editing `.bashrc`.
- Understand aliases before using them in administrative workflows.
- Investigate unexpected resource usage.
